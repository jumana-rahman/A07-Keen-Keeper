<h1>📌 KeenKeeper</h1>

<h2>🧡 Project Name</h2>
<p><b>KeenKeeper — Friendship Tracking & Relationship Management App</b></p>

<hr />

<h2>📖 Short Description</h2>
<p>
KeenKeeper is a modern web application built with Next.js that helps users manage and track their friendships.  
It allows users to monitor interaction history, view relationship stats, and stay connected through calls, texts, and video check-ins.
</p>

<p>
The app includes a timeline system, analytics dashboard, and detailed friend profiles with a clean and responsive UI.
</p>

<hr />

<h2>🛠️ Technologies Used</h2>
<ul>
  <li>Next.js</li>
  <li>Tailwind CSS</li>
  <li>DaisyUI</li>
  <li>Recharts</li>
  <li>React Toastify</li>
  <li>Local Storage</li>
  <li>React Icons</li>
</ul>

<hr />

<h2>⭐ Key Features</h2>

<h3>👥 Friend Management</h3>
<ul>
  <li>Display friends from JSON data</li>
  <li>Detailed friend profile pages</li>
  <li>Status-based UI (overdue, on-track, almost due)</li>
</ul>

<h3>⚡ Timeline System</h3>
<ul>
  <li>Logs all interactions (Call, Text, Video)</li>
  <li>Stores history using localStorage</li>
  <li>Filter timeline by interaction type</li>
</ul>

<h3>📊 Analytics Dashboard</h3>
<ul>
  <li>Pie chart visualization using Recharts</li>
  <li>Shows interaction breakdown (Call/Text/Video)</li>
  <li>Clean and responsive data representation</li>
</ul>
